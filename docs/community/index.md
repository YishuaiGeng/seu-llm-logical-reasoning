# 参与共建

知识库的价值来自持续的阅读、实践与讨论。你可以补充一个定义、纠正一处推导、复现一段代码，也可以分享一次组会留下的新问题。

## 选择你的第一步

| 想贡献什么 | 从哪里开始 |
| --- | --- |
| 整理概念或方法 | [学习笔记模板](../../templates/note.md) |
| 阅读一篇论文 | [论文阅读模板](../../templates/paper.md) |
| 分享操作经验 | [教程模板](../../templates/tutorial.md) |
| 归档一次组会 | [组会模板](../../templates/meeting.md) |
| 修正文档或链接 | [贡献指南](../../CONTRIBUTING.md) |
| 推荐论文或讨论问题 | [GitHub Discussions](https://github.com/YishuaiGeng/seu-llm-logical-reasoning/discussions) |

## 一次贡献如何进入知识库

**创建分支 → 使用模板 → 提交 PR → 同伴审阅 → 合并发布。**

尚未写完的内容可以提交 Draft PR。最终答案、原文主张、自己的理解与未验证假设应清楚区分。审阅关注可读性、来源与证据，不要求每篇笔记都成为完整论文。

## 共同维护的约定

- [贡献指南](../../CONTRIBUTING.md)：命名、归档、提交和审阅。
- [行为准则](../../CODE_OF_CONDUCT.md)：尊重、署名与协作。
- [许可与署名](license.md)：文档和代码的开放方式。
- [安全与隐私](../../SECURITY.md)：敏感问题的报告渠道。

公开知识库只收录可公开分享的材料。内部组会可以在独立私有空间完成，整理后的公开版本再提交到这里。
