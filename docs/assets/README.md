# 文档附件

按主题创建子目录，例如 `logic-foundations/`，保存笔记引用的图片和小型附件。文件名描述内容，引用使用相对路径。

图片说明注明来源或标记为自绘。论文全文、大型课件、视频、数据集与模型权重优先使用外部链接，并确保目标读者可以访问。

`brand/` 目录保存项目横幅与东南大学校徽。`seu-lockup-source.png` 是校徽原始文件，`seu-emblem.png`（圆形校徽，已加白底）、`seu-lockup.png`（浅色背景横版）、`seu-lockup-white.png`（深色背景反白横版）和 `favicon.png` 由它生成。校徽版权归东南大学所有，不适用本项目许可，详见[许可与署名](../community/license.md)。
