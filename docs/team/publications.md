# 研究成果

小组成员的论文发表与投稿进展，按最近一次状态更新的时间倒序排列。可以按状态筛选。

<!-- lr:publications -->

## 登记与更新

成果保存在仓库的 [`data/publications.yml`](https://github.com/YishuaiGeng/seu-llm-logical-reasoning/blob/main/data/publications.yml) 中。投稿、收到审稿意见、录用或正式发表后，由第一作者或组内成员更新对应条目的 `status` 与 `date` 并提交 PR。

!!! warning "登记前请确认"
    仅登记全体作者同意公开的成果。投稿会议或期刊采用匿名评审时，请将 `public` 设为 `false`：页面只显示投稿去向、状态与日期，不显示题目、作者与链接，以免违反匿名政策。未发表的想法与实验细节不在此登记。
