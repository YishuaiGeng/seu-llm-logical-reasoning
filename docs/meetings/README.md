# 组会记录

把汇报材料、讨论结论与后续行动放在同一条记录中，让每次讨论可以继续。

## 会议索引

当前尚未归档真实会议记录。首次公开记录准备完成后，按“日期、主题、汇报人、记录链接”加入本页。

## 会前、会中、会后

1. **会前**：汇报人准备论文或教程链接，列出希望讨论的问题。
2. **会中**：轮值记录人保存主要观点、分歧与支撑依据。
3. **会后**：汇报人核实技术表述，行动项明确负责人及目标日期。

文件使用 `YYYY/YYYY-MM-DD.md`，同日多场会议添加主题后缀。详细汇报内容链接原笔记，不重复复制。

使用[组会模板](../../templates/meeting.md)。公开记录须经相关成员确认可分享；未发表想法、内部实验与私人信息保存在独立私有空间。
