# 蕴涵、有效性与反例

前置知识：命题的真与假。

## 一个常见混淆

“模型给出了正确答案”和“模型给出了有效推理”是两件需要分别检查的事。模型可能猜中结论，也可能从错误前提出发，使用有效形式推出一个不符合事实的结论。

在经典命题逻辑中，我们可以把这一差别说得更精确。

## 蕴涵是连接词

`P → Q` 是一个命题公式，称为实质蕴涵。它只在 `P` 为真、`Q` 为假时取假；其余情况下取真。

| P | Q | P → Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

这是经典命题逻辑的真值定义，不自动表达时间先后或因果关系。自然语言里的“如果”也不总能无损地转换成实质蕴涵。

## 逻辑后承描述前提与结论的关系

$\Gamma \models Q$ 表示：所有让前提集合 $\Gamma$ 中每个公式为真的赋值，也都让结论 $Q$ 为真。

例如：

```derivation
P → Q
P
--- 肯定前件
Q
```

这是肯定前件（modus ponens）。不存在“两个前提都真、结论却假”的赋值，因此推理形式有效。

这里 $\to$ 是公式内部的连接词，$\models$ 是描述语义后承的符号，两者不能直接混用。

## 一个反例就能否定有效性

把第二个前提与结论交换：

```derivation
P → Q
Q
--- !肯定后件
P
```

这叫肯定后件，是无效推理。取 `P = 假`、`Q = 真`，两个前提都真，而结论 `P` 为假。这就是反例。

例如，“如果下雨，那么地面湿；地面湿；所以一定下雨”忽略了其他使地面湿的可能原因。自然语言例子只帮助直觉理解，形式有效性由上述赋值关系判定。

## 有效不等于健全

- **有效（valid）**：只要求不存在前提全真、结论为假的情形。
- **健全（sound）**：推理有效，且前提实际上都为真。

如果前提本身不可能同时为真，则经典语义下它们对任意结论都构成后承；这并不意味着前提有用或可信。因此实践中还要检查前提是否可满足。

## 对大模型评测的启发

1. 分别记录最终答案是否正确、推理步骤是否有效。
2. 检查模型使用的是题目给定前提，还是额外引入的假设。
3. 用反例和等价改写辅助分析，避免只看语言流畅度。
4. 明确形式化范围：命题逻辑中的枚举检查不能直接验证任意自然语言论证。
