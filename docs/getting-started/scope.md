# 研究范围与内容边界

## 核心问题

本项目关注：大模型能否依据给定前提进行可靠推导，哪些机制改善其逻辑推理能力，以及如何用可检验的证据评估这些能力。

不预设“生成了推理过程”就意味着逻辑正确；应区分最终答案、推导有效性、对前提的依赖、稳健性与泛化。

## 收录范围

| 层次 | 内容 | 收录要求 |
| --- | --- | --- |
| 核心 | 命题逻辑、一阶逻辑、演绎、归纳、溯因、组合推理 | 明确问题定义与适用前提 |
| 核心 | 逻辑推理数据集、基准、验证方法与错误分析 | 解释具体测量何种能力及局限 |
| 核心 | 逻辑推理训练、提示、搜索、神经符号与求解器结合 | 说明方法机制和支撑证据 |
| 相关 | 数学、代码、常识、多跳问答与规划 | 写出与逻辑推理的联系，不能仅因含 reasoning 就视为同一任务 |
| 支撑 | 模型调用、PyTorch、评测脚本、Git 与环境配置 | 服务于组内明确的学习或实验任务 |
| 外部 | 完整科研工程、通用工具项目、大型数据 | 单独维护，本仓库保留带说明的链接 |

## 整理边界

- 单篇论文的详细分析放论文笔记；跨论文的方法比较放主题笔记。
- 可以照着完成任务的步骤放教程；纯概念解释放主题笔记。
- 组会保存讨论与行动，不复制所有汇报正文。
- 个人假设可以记录，但需标记为假设，并保留待验证问题。
- 无关个人资料和临时文件不进入知识库。

## 分享边界

本知识库收录可公开分享的学习与研究材料。未发表想法、内部实验、未获作者同意公开的汇报材料保存在独立私有空间；经作者和维护者整理后，再提交可公开版本。

外部论文、课程和课件优先提供合法来源链接；少量引用注明出处。大型文件使用组内共享存储，并说明访问要求。
