## 第一次贡献

与维护者选择一个小任务：整理一个逻辑概念、阅读一篇[候选论文](../papers/README.md#candidates)，或验证一个教程步骤。使用[模板](../../templates/README.md)新增一个文件并提交 PR，导航与索引会自动更新。

第一次贡献不要求覆盖整个方向。写清来源、自己的理解和仍然不懂的问题，就可以进入审阅。

## 组会准备

汇报前准备材料入口和希望讨论的问题。汇报后检查组会记录对自己结论的转述，补充必要来源，并认领相关行动项。

## 推荐的第一组材料

1. [蕴涵、有效性与反例](../notes/logic-foundations/implication-and-entailment.md)：建立基本概念。
2. [用真值表检查一个推理](../tutorials/truth-table.md)：运行第一个验证程序。
3. [用 Z3 检查有效性与反例](../tutorials/z3-validity.md)：把同样的问题交给求解器。
4. [阅读与验证方法](reading-guide.md)：准备自己的第一篇论文笔记。
