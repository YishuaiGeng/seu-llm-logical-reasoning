# 新成员指南

## 先了解什么

先读[研究范围](scope.md)和[贡献指南](../../CONTRIBUTING.md)，了解项目关注的问题及材料放置方式。

建议的学习顺序如下。这是一条可调整的学习路线，具体已有内容见各栏目索引。

1. **逻辑基础**：命题与谓词、有效性与可满足性、演绎、归纳、溯因；辨别有效推导和经验上可信的判断。
2. **大模型基础**：自回归生成、提示、上下文学习、训练与推理的区别；理解模型生成解释与形式证明之间的差别。
3. **推理方法**：中间推理步骤、多次采样、搜索、工具与符号求解器；比较它们各自提供了什么额外机制。
4. **训练与验证**：监督微调、结果与过程反馈、验证器；理解奖励或评分是否真正对应任务目标。
5. **评测实践**：任务定义、数据划分、泄漏与记忆、扰动一致性、证明检查和误差分析。

## 第一次贡献

与维护者选择一个小任务：整理一个逻辑概念、阅读一篇指定论文，或验证一个教程步骤。使用[模板](../../templates/README.md)提交 PR，并在所属目录添加链接。

第一次贡献不要求覆盖整个方向。写清来源、自己的理解和仍然不懂的问题，就可以进入审阅。

## 组会准备

汇报前准备材料入口和希望讨论的问题。汇报后检查组会记录对自己结论的转述，补充必要来源，并认领相关行动项。

## 推荐的第一组材料

1. [蕴涵、有效性与反例](../notes/logic-foundations/implication-and-entailment.md)：建立基本概念。
2. [用真值表检查一个推理](../tutorials/truth-table.md)：运行第一个验证程序。
3. [阅读与验证方法](reading-guide.md)：准备自己的第一篇论文笔记。
