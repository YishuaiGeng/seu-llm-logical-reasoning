# 论文阅读

围绕**问题、方法、证据、局限**记录阅读过程，保留可以回到原文核实的线索。

## 阅读索引

首批精读笔记正在等待成员贡献。这里仅收录有实质分析的阅读记录，论文推荐可以先放到 [Discussions](https://github.com/YishuaiGeng/seu-llm-logical-reasoning/discussions)。

## 一份笔记应包含什么

- 核实后的题名、作者、版本与原文链接。
- 论文如何定义逻辑推理任务，采用哪些输入与评测指标。
- 方法机制、关键实验与证据的适用范围。
- 作者承认的局限、阅读者的疑问和复现状态。

先看[阅读与验证方法](../getting-started/reading-guide.md)，再复制[论文模板](../../templates/paper.md)。按论文发表或预印本年份建立目录；多次讨论链接同一份主笔记。
