# 实验与教程示例

这里只保存支持学习和教程的小型代码。完整科研工程使用独立仓库，并从相关教程链接过去。

每个示例使用独立子目录，至少说明：

- 对应教程与学习目标。
- 环境、依赖和运行命令。
- 输入或数据的来源与获取方式。
- 预期输出及实际验证状态。
- 一个或多个 `check_*.py` 自检脚本：成功时以零状态退出。CI 会自动发现并运行它们；若有第三方依赖，写在示例目录的 `requirements.txt` 中。
- 运行需要的模型、硬件或外部 API。

## 已有示例

- [真值表与逻辑后承](truth-table/README.md)：Python 标准库示例，检查有效推理并搜索反例。
- [Z3 有效性检查](z3-validity/README.md)：用 SMT 求解器检查命题与一阶推理，并读出反例。

不提交模型权重、大型数据、真实凭据或完整训练日志。
