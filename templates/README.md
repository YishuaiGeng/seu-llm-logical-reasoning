# 内容模板

| 内容 | 模板 | 目标目录 |
| --- | --- | --- |
| 学习笔记 | [note.md](note.md) | `docs/notes/` |
| 论文阅读 | [paper.md](paper.md) | `docs/papers/<year>/` |
| 实践教程 | [tutorial.md](tutorial.md) | `docs/tutorials/` |
| 组会记录 | [meeting.md](meeting.md) | `docs/meetings/<year>/` |

复制模板到目标位置后填写元信息，按需删除提示文字和不适用章节。模板中的占位字段是待填写内容，不是真实记录。

完成后更新目标目录索引。图片与其他笔记链接应根据新文件的位置编写相对路径。
